# thebreadishard.github.io

Source of the blog at https://thebreadishard.github.io/ — a public lab notebook for the
capstone project in [udacity-capstone-plan](https://github.com/thebreadishard/udacity-capstone-plan).

Built by GitHub Pages with Jekyll and the `minima` theme; no local build needed.

- New post: add `_posts/YYYY-MM-DD-slug.md` with a `layout: post` front matter and push.
- Draft: put it in `_drafts/` instead; drafts are not published.
- Rules: every number comes from a script in the project repository and each post links
  to the commit it describes; no sealed values; corrections are added, dated, at the bottom
  of a post rather than by rewriting it.
